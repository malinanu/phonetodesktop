About Send files

Works on any device with a modern browser, on the same Wi-Fi or across the internet.

Lanyard includes this file sharing page, built on FileSync. It moves files between devices with end-to-end encryption.

No account and no app: open the room link on each device. One device can send to many, and everyone in the room can send.

How it works

Files travel peer to peer over WebRTC, directly from the sender to the receiver.

A small signaling server only introduces the devices to each other. When two devices cannot reach each other directly, an encrypted relay passes the data along. Neither can read your files, and nothing is stored.
