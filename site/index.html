Phone Remote

Your phone is the remote for your computer.

Play, pause, skip, seek and change volume on your Windows, Mac or Linux computer from your phone, over your own Wi-Fi. Send files of any size between any devices, privately. No ads, no tracking.

Download All downloads

Free and open source. Windows 10/11 · macOS 11+ · Linux · Android 9+

Get connected in 60 seconds

  1. Install Phone Remote on your computer and open it. A dashboard shows a QR code.
  2. Install the phone app, then scan the QR code with it.
  3. Approve the phone on your computer. Done — it stays paired until you remove it.

Both devices must be on the same Wi-Fi. On Android, Bluetooth mode needs no computer software at all: the phone acts as a Bluetooth keyboard with media keys.

First-run notes

Windows: "Windows protected your PC"

The installer is not yet signed by a known publisher, so SmartScreen warns. Choose More info → Run anyway. When it asks, allow access on Private networks so your phone can reach the PC.

macOS: "can't be opened" and permissions

Open the .dmg and drag Phone Remote to Applications. If macOS says it cannot verify the app, right-click it and choose Open once. Then allow Accessibility (System Settings → Privacy & Security) so the phone can use the media keys, mouse and keyboard, and allow Local Network when asked. Song title and progress are not available on macOS; play, pause, skip and volume work.

Linux: install and requirements

Debian and Ubuntu: sudo apt install ./phone-remote_*.deb. Other distributions: unpack the .tar.gz and run ./install.sh. Then open Phone Remote from your applications menu, or run phone-remote open. Players that support MPRIS (Spotify, VLC, Firefox, Chromium, Rhythmbox, mpv with the MPRIS script) show title and progress. Mouse and keyboard control needs an X11 session (XWayland also works); a Wayland-only desktop may block it. Volume uses PipeWire (wpctl) or PulseAudio (pactl).

Verify a download

Every release lists SHA-256 checksums (SHA256SUMS). Compare with sha256sum file (Linux), shasum -a 256 file (macOS) or certutil -hashfile file SHA256 (Windows).

Send files, too

Click Send files on your computer, scan its code with your phone, and pick files. They go straight from device to device over your Wi-Fi, encrypted, with no size limit, nothing to set up and nothing uploaded anywhere.

Open Send files

Built on FileSync (MIT). It is built into the Phone Remote program on your computer. For sending between different networks you can run your own server.

Private by design

Stays on your network

Remote-control commands go straight from phone to computer. There is no server in the middle.

You approve every phone

Pairing needs your OK on the computer, and any phone can be revoked at any time.

No tracking

No ads or analytics. Files are never stored. Read the privacy policy.

Good to know

  • Phone-to-computer traffic is encrypted and pinned to your computer's own key, and only private (home-network) addresses are accepted. Phones on older app versions use plain HTTP until you switch that off in the computer's dashboard.
  • Bluetooth mode (Android only) can't show what's playing, and seeks with the arrow keys.
  • iPhones cannot act as a Bluetooth keyboard, so the iPhone app works over Wi-Fi only.
